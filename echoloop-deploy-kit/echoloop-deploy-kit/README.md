# Echo Loop 自用全功能 · 部署工具包

> 这是一份**自包含**的工具包，直接交给**你电脑里的 agent**，它就能照着把整套环境搭起来。
> 目的：让孩子在一台 Android 学习机上，免订阅、免登录，用上 Echo Loop 的**全部功能**
> （翻译 / 解析 / 意群 / 词典 / 转录字幕），数据留在你自家局域网。

---

## 怎么交给 agent

把整个 `echoloop-deploy-kit/` 文件夹（或下面的 `echoloop-deploy-kit.zip`）
交给你的 agent，对它说：

> **「按包里的 AGENT.md 帮我部署 Echo Loop 自用全功能版。」**

agent 会先读 `AGENT.md`，按里面的步骤执行；缺什么信息（IP、Key 等）它会主动问你。

---

## 包里有什么

| 文件 | 给谁看 | 用途 |
|------|--------|------|
| `AGENT.md` | **你的 agent** | 执行简报：目标、文件清单、每步命令、坑点 |
| `backend/` | agent → 工控机 | 自建 AI 后端（已测通 12 项接口） |
| `client-patch/apply_unlock.py` | agent → 编译机 | 客户端去锁补丁（付费墙/登录/鉴权/Android明文） |
| `docs/部署手册.md` | 你（备查） | 人读详细手册 |
| `backend/self_test.py` | agent | 后端「无 Key 自检」（部署后必跑） |

---

## 你需要提前准备、交给 agent 的信息

1. **工控机局域网 IP**（如 `192.168.1.50`）——App 访问后端的地址。
2. **DeepSeek API Key**（翻译/解析/意群/词典必需，极便宜）。
3. 是否要 **AI 转录字幕**？要则还需 **OpenAI API Key**（可选）。
4. **编译 APK 的机器**在哪？你电脑里的 agent 所在机器是否已装 **Flutter 3.9.2+ 和 Android SDK**？
5. **学习机是 Android**？能否开「未知来源安装」？

> 你不用自己操作命令，把上面这些信息提供给 agent 即可。

---

## agent 会替你做

- 把 `backend/` 部署到你家 **7×24 的 Ubuntu 工控机**，常驻 AI 后端。
- 在装了 Flutter 的机器上，**克隆官方仓库 → 跑去锁补丁 → 编译去锁版 APK**。
- 把 APK 装到孩子的 Android 学习机，并确认同局域网能联调。
- 跑 `self_test.py` 自检后端 12 项接口，确认无误。
