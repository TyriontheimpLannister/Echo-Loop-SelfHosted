# Echo Loop 自用部署手册（给孩子用 · 全功能免订阅版）

> 目标：让孩子在一台 **Android 学习机** 上，用上 Echo Loop 的**全部功能**（含官方要订阅的
> AI 翻译 / 解析 / 意群 / 词典 / 转录字幕），完全免费、数据留在自家局域网。
>
> 环境：家里一台 **j4125 Ubuntu 工控机 7×24 开机** 跑 AI 后端；学习机只装 App。

---

## 一、整体架构

```
┌─────────────────────┐         HTTP(局域网)          ┌──────────────────────────┐
│  Android 学习机      │ ───────────────────────────▶ │  j4125 工控机 (Ubuntu)    │
│  Echo Loop App      │   API_BASE_URL=              │  ┌──────────────────────┐ │
│  (去锁版, 全解锁)    │   http://192.168.1.50:8000   │  │ AI 后端 FastAPI :8000 │ │
│                      │ ◀─────────────────────────── │  │  ├ 翻译/解析/意群/词典 │ │
└─────────────────────┘         JSON 结果            │  │  └ 转录(Whisper)      │ │
                                                  │  └──────────────────────┘ │
                                                  │  调用 DeepSeek / OpenAI     │
                                                  └──────────────────────────┘
```

- **工控机**：只负责跑 AI 后端（轻量，j4125 毫无压力）。
- **编译 App**：在**任意一台装了 Flutter 的电脑**上编译一次 APK 即可（不必是工控机）。
- **学习机**：同局域网访问工控机后端。

## 二、准备清单

| 物品 | 用途 | 必需 |
|------|------|------|
| 工控机局域网 IP（如 192.168.1.50） | App 访问后端的地址 | ✅ |
| DeepSeek API Key | 翻译/解析/意群/词典（极便宜） | ✅ |
| OpenAI API Key | AI 自动出字幕（转录），不要转录可省 | ⚪ 可选 |
| 一台能装 Flutter 的电脑（Win/Mac/Linux） | 编译 APK（一次性） | ✅ |
| 学习机「允许未知来源安装」 | 装 APK | ✅ |

> 获取 Key：DeepSeek 官网 `platform.deepseek.com` 注册充值拿 Key；OpenAI 同理。
> 孩子日常使用，DeepSeek 每月约 **¥1–5**，转录按需另算（几分钟音频约几分钱）。

## 三、步骤一：工控机部署 AI 后端

SSH 进工控机执行：

```bash
# 1. 装 Python 虚拟环境工具
sudo apt update && sudo apt install -y python3-venv python3-pip

# 2. 把本仓库的 echoloop-ai-backend/ 目录传到工控机 /opt/echoloop-ai-backend
#    （用 scp / U 盘 / 网盘均可）

# 3. 建环境、装依赖
cd /opt/echoloop-ai-backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 4. 配置密钥
cp .env.example .env
#   编辑 .env，至少填 LLM_API_KEY=sk-你的deepseekkey
#   需要转录则填 OPENAI_API_KEY=sk-你的openaikey

# 5. 先前台测试
python main.py
#   另开终端：curl http://localhost:8000/  → 看到 {"status":"ok"} 即成功
#   Ctrl+C 退出
```

**设为开机自启（推荐）**：把 `README.md` 里的 systemd 片段写入
`/etc/systemd/system/echoloop-ai.service`（注意改 `WorkingDirectory` 和 `User`），然后：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now echoloop-ai
sudo ufw allow 8000   # 放行端口，让学习机访问
```

## 四、步骤二：编译「去锁版」App（任意电脑）

在**装了 Flutter 的电脑**上（无需是工控机）：

```bash
# 1. 环境（如已具备可跳过）
#   - Flutter 3.9.2+，且 flutter doctor 无红叉
#   - Java 17、Android SDK（cmdline-tools + build-tools;34.0.0 + platforms;android-34）
#   - flutter doctor --android-licenses 全部同意

# 2. 拉官方仓库
git clone https://github.com/echo-loop/Echo-Loop.git
cd Echo-Loop

# 3. 跑去锁补丁（自动改 4 个文件：付费墙/伪登录/AI鉴权/Android明文）
python3 /path/to/echoloop-ai-backend/apply_unlock.py

# 4. 配置编译变量
cp .dev.env.template .dev.env
#   编辑 .dev.env，关键两行：
#     SUPABASE_URL=                       ← 留空（App 会跳过登录，零崩溃风险）
#     SUPABASE_PUBLISHABLE_KEY=           ← 留空
#     API_BASE_URL=http://192.168.1.50:8000   ← 改成你工控机真实局域网 IP
#     REVENUECAT_*=                       ← 全部留空
#   （其它 GOOGLE_WEB_CLIENT_ID 等也留空即可）

# 5. 编译 APK
flutter pub get
dart run build_runner build
flutter build apk --dart-define-from-file=.dev.env
#   产物：build/app/outputs/flutter-apk/app-release.apk
```

> 补丁已验证可复现、幂等；如需回退，用 `git checkout` 还原那 4 个文件即可。

---

## 五、步骤三：装到学习机

任选一种：

- **U 盘/网盘**：把 `app-release.apk` 拷到学习机，文件管理器点开安装（需开「未知来源」）。
- **ADB**：学习机开 USB 调试连电脑，`adb install app-release.apk`。
- **局域网**：工控机上 `cd build/app/outputs/flutter-apk && python3 -m http.server 8080`，
  学习机浏览器开 `http://192.168.1.50:8080/app-release.apk` 下载安装。

## 六、步骤四：学习机联调

1. 学习机与工控机在**同一 WiFi/局域网**。
2. 打开 App → 导入一段英语音频（或打开任意句子点「翻译」）。
3. 请求会发到 `http://192.168.1.50:8000`，后端调 LLM 返回结果。
4. 全部 AI 功能应**无需登录、无订阅提示**直接可用。

**固定地址（重要）**：若工控机 IP 是 DHCP 分配、可能变化，二选一：
- 路由器后台把工控机 MAC 绑定固定 IP；**或**
- 用内网穿透（frp / Cloudflare tunnel）给后端一个固定域名（用 HTTPS 域名时，
  步骤二第 4 步的 `android:usesCleartextTraffic` 不再是必需，但留着无害）。

## 七、常见问题排查

| 现象 | 排查 |
|------|------|
| App 启动白屏/报 Supabase | `.dev.env` 里 Supabase 留空即可跳过；若仍报错，把日志发我 |
| 点翻译/解析无反应或报错 | 工控机 `curl http://localhost:8000/` 看后端在跑；查 ufw 是否放行 8000；API_BASE_URL 的 IP 是否正确 |
| `Cleartext HTTP ... not permitted` | apply_unlock.py 已自动加 `usesCleartextTraffic="true"`；重编 APK 生效 |
| 转录没结果 | 需 `OPENAI_API_KEY` 且音频上传成功；看工控机后端日志 |
| LLM 超时/报错 | DeepSeek Key 是否正确、余额是否足；翻译接口超时 60s |
